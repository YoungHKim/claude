# 카드뉴스 스튜디오 사용설명서

지원사업·제도처럼 여러 항목을 정리해 알려 주는 인스타 카드뉴스를, Claude Code와 함께 만들어 PNG까지 뽑는 도구입니다.

제공: 마음인베스트먼트

---

## 1. 받은 파일

| 파일 | 내용 |
|---|---|
| `카드뉴스_스튜디오_사용설명서.md` | 지금 보는 문서 |
| `카드뉴스_스튜디오.zip` | 스튜디오 전체 |

---

## 2. 준비물

| 필요한 것 | 어디에 쓰나 | 설치 |
|---|---|---|
| Node.js | 스튜디오 화면, 렌더 (필수) | https://nodejs.org 에서 LTS 설치 |
| Claude Code | 카드 만들기 | 데스크톱 앱 또는 터미널 |
| Python + Pillow | 원고로 카드 생성 | https://www.python.org 설치 후 `pip install pillow` |

화면을 구경하고 글자만 고칠 때는 Node.js만 있어도 됩니다.

---

## 3. 시작하기

1. `카드뉴스_스튜디오.zip`의 **압축을 풉니다.** 압축 파일 안에서 바로 실행하면 동작하지 않습니다.
2. 폴더를 원하는 곳에 둡니다. 예: 바탕화면
3. 폴더 안의 시작 파일을 더블클릭합니다.
   - **Windows:** `시작하기.bat`
   - **맥:** `시작하기.command`
4. 브라우저가 열리고 http://localhost:5174 에 스튜디오가 뜹니다.

**처음 한 번**은 렌더용 브라우저를 약 200MB 내려받느라 몇 분 걸립니다.

검은 창(터미널)을 닫으면 스튜디오도 꺼집니다. 쓰는 동안 열어 두세요.

### 맥에서 "확인되지 않은 개발자" 경고가 뜨면

`시작하기.command`를 **우클릭 → 열기**를 누릅니다. 그래도 안 되면 터미널에서 폴더로 이동해 아래를 한 번 실행합니다.

```bash
xattr -dr com.apple.quarantine . && chmod +x 시작하기.command
```

## 4. Claude Code로 카드뉴스 만들기

Claude Code에서 **압축을 푼 폴더를 엽니다.** 폴더의 `CLAUDE.md`를 Claude가 읽고 규칙대로 작업합니다.

처음에는 이렇게 말하세요.

```
이 폴더 CLAUDE.md 읽고 환경 확인해 줘. 브랜드 글자는 ○○○으로 바꿔 줘.
```

그다음부터는 이렇게 말합니다.

```
정보제공용 카드뉴스 만들어줘. 주제는 수출지원사업 5가지.
```

```
카드뉴스 2026-11-info-01 글자만 고쳐줘. 2번 카드 금액을 ○○로.
```

```
카드뉴스 만들어줘. 주제는 ○○. 레퍼런스 패널(2026-11-pet-food)의 레퍼런스 1처럼 만들어 줘.
```

Claude가 하는 일은 다음과 같습니다.

| 순서 | 할 일 | 누가 |
|---|---|---|
| 1 | 주제 정하기 | 사람 |
| 2 | 공식 공고 조사, 확인한 값만 정리 | Claude |
| 3 | 원고 파일 작성 | Claude |
| 4 | 공식 사이트 화면 캡처 | Claude 또는 사람 |
| 5 | 표지 사진 준비 | 사람 또는 이미지 생성 도구 |
| 6 | 카드 생성, 렌더, 눈으로 검수 | Claude |
| 7 | 최종 확인 | 사람 |
| 8 | PNG 내보내기 | Claude 또는 화면 버튼 |
| 9 | 인스타 게시 | 사람 (자동 게시 기능은 없습니다) |

## 5. 스튜디오 화면

### 관리 화면 (http://localhost:5174)

| 칸 | 할 수 있는 일 |
|---|---|
| 작업 목록 | 최근 수정한 순으로 주제가 보입니다. **열기**, **검수 렌더**, **PNG 내보내기**, **삭제** |
| 만들기 01 | 새 주제 만들기. 고른 주제를 복사해 새 폴더를 만듭니다 |
| 만들기 02 | 레퍼런스로 만들기. 캡처를 붙여넣고 문장을 복사해 Claude에게 보냅니다 |

### 편집 화면 (주제를 연 화면)

1. 아래 검은 바에서 **글자 편집**을 누릅니다.
2. 글자를 클릭해서 고칩니다. 글자를 끌어 선택하면 강조, 형광펜 같은 서식 바가 뜹니다.
3. **저장** 또는 **Ctrl+S**를 누릅니다.

사진은 칸에 끌어다 놓으면 바뀝니다.

왼쪽 **주제 목록** 칸에서는 관리 화면으로 나가지 않고 다음을 할 수 있습니다.

- 여태 만든 주제를 보고 바로 옮겨 가기
- **새 주제 만들기**로 새 주제를 만들고 바로 열기
- **삭제**

칸은 아래 검은 바의 **주제 목록** 버튼으로 여닫습니다.

### 알아두세요

- **삭제**는 폴더를 `_휴지통`으로 옮기는 것입니다. 되돌리려면 탐색기에서 `projects`로 다시 옮기세요. 완전히 지우려면 `_휴지통`에서 직접 지웁니다. 마지막 한 편은 지워지지 않습니다.
- **새 주제**는 고른 주제의 복사본이라 처음엔 내용이 이전 주제 그대로입니다.
- 편집 화면에서 고친 뒤 Claude가 **원고로 다시 생성하면 덮어써집니다.** 고친 내용을 원고에도 반영해 달라고 말하세요.
- Claude가 파일을 고친 뒤에는 편집 화면을 새로고침하세요. 먼저 열어 둔 탭에서 저장하면 서버가 막습니다.
- 저장 직전 사본이 주제 폴더의 `.backup`에 최신 10개까지 남습니다.

## 8. 표지 사진 프롬프트

이미지 생성 도구에 넣는 틀입니다. `<...>` 자리만 주제에 맞게 바꿉니다.

```
Editorial concept photograph shot on 35mm film. <인물 + 주제를 상징하는 물건을 다루는 장면>. Plain pale desaturated backdrop, soft natural daylight, gentle film grain, muted tones with one vivid accent color. Composition: the head sits very high in the frame, the top of the hair at about 12 percent of the image height from the top, the eyes at about 24 percent, the chin at about 38 percent. Vertical 3:4. No text, no letters, no logos, no watermark.
```

**구도 숫자를 빼지 마세요.** 표지 아래쪽은 그늘로 덮이기 때문에, 턱이 40% 아래로 내려가면 얼굴이 가려집니다.

## 9. 지켜야 할 것

1. **확인한 값만 씁니다.** 금액, 대상, 기간은 공식 공고에서 확인하고 출처를 남깁니다.
2. **확인일을 남깁니다.** 지원사업은 자주 바뀌므로 카드에 기준일을 적습니다.
3. **레퍼런스는 참고만 합니다.** 배치, 글자 크기, 색, 말투만 참고합니다. 다른 계정의 글, 사진, 로고는 쓰지 않습니다.
4. **샘플은 게시하지 않습니다.** `2026-11-info-00`의 사업 이름과 금액은 자리표시이고, 사진과 캡처도 예시입니다.
5. **공식 화면 캡처는 게시 전에 확인합니다.** 기관 로고가 들어가므로 사용해도 되는지 판단합니다.

## 10. 자주 막히는 것

| 증상 | 원인 | 해결 |
|---|---|---|
| "서버가 꺼져 있습니다" | 검은 창을 닫음 | `시작하기`를 다시 실행 |
| 시작 파일이 바로 꺼짐 | Node.js 없음 또는 압축을 안 풂 | Node.js 설치, 압축 풀기 |
| 이미 사용 중이라는 오류 (`EADDRINUSE`) | 스튜디오가 이미 켜져 있음 | 켜진 검은 창을 쓰거나 닫고 다시 실행 |
| 검수 렌더에 Playwright 안내가 뜸 | 처음 설치가 안 끝남 | 화면에 뜬 명령을 터미널에서 실행 |
| 브라우저 PNG 버튼이 반응 없음 | 파일을 더블클릭해서 열었거나 인터넷이 끊김 (이 버튼은 인터넷 연결이 필요합니다) | http://localhost:5174 로 열기, 또는 관리 화면의 **PNG 내보내기** 사용 |
| `카드 밖으로 벗어남` | 본문이 너무 많음 | 줄이거나 항목을 나누기 |
| 표지 얼굴이 가려짐 | 사진 구도가 낮음 | 프롬프트의 구도 숫자를 넣어 다시 생성 |
| 표지 제목이 너무 작음 | 한 줄이 너무 김 | 줄을 나누기 |
| 이미지를 바꿨는데 그대로임 | 이미 있으면 건너뜀 | Claude에게 "사진 다시 잘라서 생성해 줘" |
| 고친 글자가 사라짐 | 원고로 다시 생성함 | 원고에도 반영 |
