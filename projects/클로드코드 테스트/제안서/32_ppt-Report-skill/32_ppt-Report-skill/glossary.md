# 용어 사전 (glossary.md)

보고서에 나오는 용어를 **누구나 아는 쉬운 말**로 풀이한 사전입니다. (공통 자산 — 어느 프로젝트에나 재사용)

> **쓰는 법**
> - 슬라이드에 어려운 용어가 나오면, 여기 풀이를 **한 줄로 요약해** 함께 넣습니다.
> - 화면에서는 `.gloss`(설명 박스) 또는 `.why`(작은 괄호 풀이) 컴포넌트를 씁니다. (예시는 `examples/`)
> - 워딩 원칙은 `CLAUDE.md`의 「워딩(카피) 원칙」을 따릅니다. **여기 없는 용어를 새로 쓰면 이 사전에 추가**합니다.

## 1. 기본 성과 지표

| 용어 | 쉬운 뜻 |
|---|---|
| **조회수** | 영상이 사람들에게 보인 횟수. (한 사람이 여러 번 봐도 카운트) |
| **좋아요** | 영상에 하트를 누른 횟수. |
| **댓글** | 영상에 달린 댓글 수. (대댓글 포함 여부는 그때그때 표시) |
| **저장(북마크)** | **나중에 다시 보려고 담아둔 횟수.** 그냥 보고 지나간 것과 다른 '관심 신호'. |
| **공유** | **친구에게 보내준 횟수.** 남에게 퍼뜨렸다는 뜻이라 확산의 출발점. |
| **팔로워** | 그 크리에이터 계정을 구독하는 사람 수. |

## 2. 행동·관여 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **인게이지먼트(engagement)** | '관여'라는 뜻. 좋아요·댓글·저장·공유처럼 **그냥 보기만 한 게 아니라 뭔가 행동한 것**을 묶어 부르는 말. |
| **인게이지먼트율 (ER)** | 본 사람이 **얼마나 깊게 반응했는지**의 비율. petoday는 아래 「스크리닝 지표」의 **가중 공식**을 쓴다. |
| **저장+공유 비율** | (저장 + 공유) ÷ 조회수. 본 사람 중 몇 %가 **다시 보거나 남에게 보낸** 행동을 했는지. 관심의 크기를 보여줌. |
| **후킹(hooking)** | 영상 맨 앞에서 **시선을 확 끄는 부분.** "이 소식 들은 사람?" 같은 첫 멘트·장면. |

## 2-1. 크리에이터 스크리닝 지표 ⭐ (크리에이터 선별에 실제 사용)

> 실집행 데이터로 검증한 크리에이터 선별 기준. **자세한 공식·등급 체계는 `screening.md`**(별도 방법론 문서)를 본다.

### ER (콘텐츠 인게이지율) — **주 지표**
- **공식**: `ER(%) = (좋아요×1 + 저장(북마크)×2 + 댓글×2 + 공유×3) ÷ 조회수 × 100`
- **재는 것**: 영상을 본 사람이 **얼마나 깊게 반응했는가** = 콘텐츠의 반응 품질·설득력.
- **가중치 이유**: 행동 강도 순. 좋아요(가벼운 호감 ×1) < 저장·댓글(관심·참여 ×2) < **공유(남에게 추천 ×3, 가장 강함)**.
- **크기와 무관**: 조회수로 나누므로 팔로워 규모와 독립. 그래서 **나노~매크로를 한 줄로 공정 비교** 가능.
- **읽는 법**: 보통 4~5%, **7% 이상이면 우수(A)**. 광고 영상은 오가닉보다 낮게 나오는 편.

### 도달배수 (Reach Multiple) — **보조 지표**
- **공식**: `도달배수 = 조회수 ÷ 팔로워`
- **재는 것**: 그 영상이 **팔로워(구독자) 밖으로 얼마나 퍼졌는가** = 추천피드(FYP) 확산의 넓이.
- **읽는 법**: `1` = 팔로워 수만큼 도달 · `1 초과` = 팔로워 밖으로 확산(바이럴 신호) · `1 미만` = 팔로워 일부만.
- **주의**: 작은 계정일수록 구조적으로 큼(나노 중앙값 1.93 vs 매크로 0.06). **절대값이 아니라 같은 크기 등급의 기준선(★)과** 비교한다.
- ER과 **독립된 다른 축**(반응 깊이 ≠ 도달 넓이). 그래서 ER로 품질을 거르고 도달배수 ★로 확산을 가산하는 **2축 방식**을 쓴다.

### 조회수 중앙값 (Median)
- **뜻**: 여러 영상의 조회수를 크기순으로 줄 세웠을 때 **딱 한가운데 값.**
- **왜 쓰나**: 평균(산술평균)은 **초대박 영상 하나에 크게 흔들리지만**, 중앙값은 '보통 이 정도'라는 **평소 실력**을 보여준다.
- 그래서 크리에이터를 볼 때 **평균과 중앙값을 같이** 본다. (예: 편당 평균 71,526 · 중앙값 14,000 → 평소엔 1.4만 정도, 어쩌다 대박이 평균을 끌어올린 것)

### 크기 등급 (팔로워 규모)
| 등급 | 팔로워 |
|---|---|
| 나노 | 1천 미만 |
| 시드 | 1천 ~ 1만 |
| 마이크로 | 1만 ~ 5만 |
| 미드 | 5만 ~ 20만 |
| 매크로 | 20만 이상 |

> **성과 등급**(A/B/C)은 ER 기준으로 크기와 무관하게 매기고, **★**는 같은 크기 등급 대비 도달배수 상위일 때 붙인다. 최종 표기 예: `미드-B★`. (기준값·백분위는 `screening.md`)

## 3. 광고·운영 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **오가닉(organic)** | **광고를 태우지 않고** 자연스럽게 노출된 것. '광고 안 한 상태'라고 보면 됨. |
| **스파크애즈(Spark Ads)** | 크리에이터가 올린 영상을 **그대로 광고로 내보내는 방식.** 새 광고를 안 만들고, 반응 좋은 영상에 돈을 얹어 더 많이 보여줌. 성과는 크리에이터 계정에도 쌓임. |
| **시딩(seeding)** | 여러 크리에이터에게 제품·메시지를 뿌려 **자연스러운 리뷰로 퍼뜨리는** 방식. ('씨를 뿌린다'는 뜻) |
| **CPM** | 1,000회 노출당 든 광고비. (Cost Per Mille) |
| **KV(키비주얼)** | 캠페인의 **대표 이미지.** Key Visual의 줄임말. |

## 4. 확산·알고리즘 관련

| 용어 | 쉬운 뜻 |
|---|---|
| **추천 피드 / FYP** | 틱톡이 **취향에 맞는 영상을 자동으로 띄워주는 화면.** For You Page. 팔로워가 아니어도 여기에 뜨면 널리 퍼짐. |
| **잔존가치** | 영상을 올린 뒤 **플랫폼이 그 영상을 계속 보여주는 기간.** 길수록 같은 비용으로 더 오래 노출됨. (petoday는 틱톡을 2~3개월로 봄) |
| **롱테일(long-tail)** | 업로드 초반이 지난 뒤에도 **조회수가 길게 이어지며 쌓이는 현상.** |
| **미러링(mirroring)** | 틱톡에 올린 영상을 **인스타그램 등 다른 곳에도 똑같이 올리는 것.** 추가 비용 없이 노출을 늘림. |
| **조회수 버림** | 틱톡이 조회수가 **100만을 넘으면 소수점 첫째 자리까지만** 보여주는 것. 실제로는 늘었는데 안 늘어난 것처럼 보일 수 있음. (예: 170만 회로 며칠째 고정 표시) |

## 5. 크리에이터 체급 (팔로워 규모 구분)

| 구분 | 대략 기준 | 역할 |
|---|---|---|
| **메가(mega)** | 팔로워 수십만~수백만 | 한 번에 넓게 알림 |
| **미드(mid)** | 팔로워 약 10만~30만대 | 넓게 알리면서 반응도 확보 |
| **시딩(seeding)** | 팔로워 수천~수만 | 수가 많고, 콘텐츠가 맞으면 폭발적 확산도 나옴 |

> ※ 프로젝트마다 정확한 팔로워 구간은 다를 수 있으니, 수치는 `project.md`를 기준으로 합니다.
