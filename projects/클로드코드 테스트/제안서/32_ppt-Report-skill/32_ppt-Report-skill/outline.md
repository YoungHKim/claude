# 결과보고서 골격 · 작성 가이드 (outline.md)

결과보고서를 **페이지 단위로 어떻게 짜고 무엇을 쓰는지**에 대한 골격 가이드입니다. (공통 자산 — 어느 프로젝트에나 재사용)

> **이 문서 vs project.md**
> - `outline.md`(여기) = **빈 골격 + 작성 지침** (페이지마다 목적·필수 요소·워딩·쓸 양식). 범용.
> - `project.md` = 그 골격에 채운 **이 보고서의 실제 페이지·수치.** 전용.
>
> **쓰는 법**: 새 보고서를 시작하면 아래 골격에서 필요한 페이지를 고르고, 실제 수치·문구는 `project.md`에서 가져와 채웁니다. 양식(HTML)은 `examples/`에서 복사합니다.

---

## 0. 전체 흐름 (표준 순서)

```
표지 → 실행요약 → 개요 →  [단계 간지 → 내용 …] × N  → (대표 콘텐츠) → (댓글) → (인사이트) → 결론
```

- **한 페이지 = 한 메시지.** 제목이 곧 그 페이지의 결론, 본문은 그 근거만.
- 이야기 순서: **무슨 일이 있었나(사실) → 그게 무슨 뜻인가(해석) → 그래서 뭘 하면 되나(제언).**
- 캠페인이 단계형(예: 발견→트리거→행동→확산, 또는 1차→2차→3차)이면 그 단계를 뼈대로 삼는다.

> ⏱ **작성 순서 ≠ 배치 순서.** 페이지가 놓이는 위치는 위 순서지만, **쓰는 순서**는 다르다.
> **실행요약(p2)은 맨 마지막에 쓴다.** 전체를 요약하는 장이라, 나머지 페이지의 수치·인사이트가 다 확정된 뒤에 써야 정확하다.
> 권장 작성 순서: **개요·내용·대표콘텐츠·인사이트 → 결론 → (맨 마지막) 실행요약.**

## 1. 페이지별 골격

각 페이지: **목적 / 필수 요소 / 워딩 포인트 / 쓸 양식(examples)**

### p1 · 표지 (Cover)
- **목적**: 보고서가 무엇인지 한눈에.
- **필수 요소**: 캠페인명 · 보고서 종류(결과보고서) · 날짜/버전/작성자 · 우리 로고. (클라이언트 로고 있으면 함께)
- **워딩**: 제목은 짧고 사실대로. 수식어 금지.
- **양식**: `cover.html`

---

### p2 · 실행요약 (Executive Summary) ⭐ 가장 중요
> 바쁜 사람이 **이 한 장만 봐도** 캠페인 결과를 알 수 있어야 한다. 뒤 페이지는 이 요약의 근거를 하나씩 펼친 것.

> ⏱ **작성은 맨 나중에.** 위치는 앞(p2)이지만, 나머지 페이지가 다 확정된 뒤에 쓴다.
> 요약에 들어갈 숫자·문장은 전부 뒤 페이지에서 나오므로, 뒤를 먼저 채우고 마지막에 '그 결과를 압축'한다.
> (단계형 요약을 쓸 때, 트리거처럼 뒷장 데이터가 필요한 칸이 있으면 그 데이터가 나온 뒤 완성한다. 예: 댓글 분류 → 트리거 %)

- **목적**: 캠페인 전체 결과를 **한 문장 + 핵심 숫자 몇 개**로 압축.
- **구성 (위→아래)**
  1. **라벨**: `EXECUTIVE SUMMARY`
  2. **제목 = 한 문장 결론.** 이 캠페인이 결국 무엇을 해냈는지. (예: "○○ 욕구와 △△가 발견부터 구매 신호까지 만들었습니다.")
  3. **본문 2~3줄**: 제목을 풀어주는 요약. 어떤 설계로, 어떤 반응이, 어떤 성과로 이어졌는지.
  4. **가로 실선**
  5. **핵심 지표 카드 3~4개 (가로 흐름)**: 캠페인의 단계나 축을 카드로. 각 카드 =
     - **작은 라벨**(단계 이름, 예: 발견 / 트리거 / 행동 / 확산)
     - **큰 숫자 1개**(그 단계의 대표 수치, 예: 132.9만 / 29% / 4,901 / +62%)
     - **불릿 2~3줄**(그 숫자의 근거·부연)
     - 카드 사이 **화살표(→)** 로 흐름을 보여줌
- **고르는 기준**: 숫자는 **뒤에서 실제로 다루는 것**만. 요약에만 나오고 근거가 없는 숫자는 넣지 않는다.
- **워딩 포인트**
  - 각 숫자 밑에는 **"무슨 뜻인지" 한 줄**을 반드시. (예: "132.9만 — 콘텐츠 59편을 합친 총 조회 수")
  - 배수·비교엔 **기준/출처**를 캡션으로. (예: "업계 평균의 2.6배 · 글로벌 기준 ○○")
  - 어려운 용어는 `glossary.md` 풀이를 한 줄로.
- **양식**: `examples/exec-summary.html` (`.flow` + `.stat-num` + `.stat-sub`)
- **체크리스트**
  - [ ] 제목만 읽어도 결과가 이해되는가
  - [ ] 카드 숫자 각각에 '무슨 뜻' 한 줄이 있는가
  - [ ] 이 페이지의 숫자가 모두 뒤에서 근거로 다뤄지는가
  - [ ] 과장 표현("압도적/폭발적") 대신 숫자로 말했는가

### p3 · 개요 (Campaign Overview)
- **목적**: 캠페인이 **어떻게** 굴러갔는지(규모·구성)를 사실 위주로. 판단·자랑은 뒤 페이지에서.

**개요에 꼭 넣는 정량지표**

- **① 전체 규모** — 원형 뱃지(`.stat-badge`)로 크게
  - 참여 크리에이터 수 · 제작 콘텐츠 수 · (권장) 총 조회수
- **② 기간** — 업로드 기간 · 성과 추적 기준일
- **③ 그룹(크기 등급)별 구성 표** — 개요의 핵심. 한 행 = 한 등급.
  - 그룹명(+인원) · 콘텐츠 수 · **팔로워 범위(min~max)** · **편당 평균 조회** · **편당 조회 중앙값** · **총 조회 비중(%)**
  - ⭐ **평균과 중앙값을 반드시 함께.** 평균은 대박 1편(또는 광고)에 크게 흔들리지만 **중앙값이 '평소 실력'** 이다. (예: 시딩 평균 18.9만 vs 중앙값 9,860 — 20배 차이)
  - 크기 등급 정의는 `glossary.md`「스크리닝 지표」, 판정 방법은 `screening.md`.
- **④ (선택) 그룹별 편당 조회수 막대차트** — 중앙값(강조) vs 산술평균. 위 표를 시각화.

> 단계형 캠페인(1차/2차/3차)은 **차수별 표**(무엇을·언제·몇 편)를 먼저, **체급별 표**(위 ③)를 그다음에. 둘을 한 장에 다 넣기 버거우면 개요 = 차수, 다음 장 = 체급별 현황으로 나눈다.

- **워딩**: 사실만. 수치엔 '무슨 뜻' 한 줄.
- **양식**: `examples/overview.html` (`.stat-badge` + `.data-table`) · 차트는 `examples/bar-chart.html`

### 단계 간지 (Section Divider)
- **목적**: 다음 묶음이 어떤 단계인지 알림. 리듬을 준다.
- **필수 요소**: 큰 번호(01~) · 단계 라벨(STAGE 01 · DISCOVERY) · 제목 한 줄 · 부제 한 줄.
- **양식**: `examples/section-divider.html`

### 내용 페이지 (Content)
- **목적**: 한 페이지에 **주장 하나 + 근거(차트/표) 하나.**
- **골격**: 라벨 → 제목(=결론) → 설명 한 줄 → 실선 → 차트/표 → 푸터.
- **차트 고르기**: 시간 흐름=라인 · 그룹 비교=막대 · 비율=도넛/순위 · 원자료=표.
- **양식**: `examples/bar-chart.html` · `line-chart.html` · `donut-rank.html`

### 대표 콘텐츠 (Best Content)
- **목적**: 성과를 낸 실제 콘텐츠를 보여줌(설득력).
- **필수 요소**: 순위 · 크리에이터명 · 체급/제품 · 핵심 지표 · 콘텐츠 특징 · 주요 댓글 · (썸네일).
- **양식**: `examples/creator-cards.html` (`.cc-thumb` = 사진 자리)

### 결론 (Conclusion)
- **목적**: 다시 요약 + **다음에 뭘 하면 좋은지(제언).**
- **필수 요소**: 이번에 확인한 것 몇 가지 · 다음 캠페인 제언 몇 가지. 제언은 **근거와 함께.**

## 2. 페이지별 실제 내용은 project.md

이 골격에 채울 **실제 페이지 목록·수치·문구**는 `project.md`의 「페이지 맵」에 적는다.
여기(outline)는 "어떻게 쓰는지", project.md는 "무엇을 쓰는지".
