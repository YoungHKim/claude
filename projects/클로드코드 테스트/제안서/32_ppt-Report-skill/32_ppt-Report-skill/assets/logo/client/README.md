# 클라이언트 / 브랜드 로고 넣는 곳

이 보고서에 들어갈 **클라이언트(고객사)·브랜드 로고**를 여기에 넣습니다.

- **파일 형식**: **SVG 권장** (크기 자유·선명). 없으면 **PNG 가능**(배경 투명·고해상도).
- **파일명**: `브랜드명-용도.svg` 형태로. 예) `brand-logo.svg`, `brand-logo-white.svg`
- 다크 배경에 검정 로고를 올릴 땐 CSS `filter: brightness(0) invert(1)`로 흰색 변환 가능(단색 로고에 한함). 색이 있는 로고는 **흰색 버전 파일을 따로** 넣는 게 가장 깔끔합니다.

> **클라이언트 로고가 필요하면 이 폴더(`assets/logo/client/`)에 넣어주세요.** 넣기 전까지는 텍스트/빈자리로 표시합니다.
