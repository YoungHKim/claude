# 디자인 시스템 & 애니메이션 가이드 (petoday 결과보고서)

이 폴더 문서는 **슬라이드의 겉모습(디자인)과 움직임(애니메이션)** 을 정의합니다.
실제 값은 `../assets/report.css`(스타일)와 `../assets/report.js`(스크립트)에 들어 있고, 이 문서는 "언제 무엇을 어떻게 쓰는지" 규칙입니다.

> 산출물 규칙·워딩 원칙·페이지 맵은 상위 폴더의 `../CLAUDE.md`를 봅니다.

---

## 1. 캔버스 / 해상도

- 한 슬라이드 = **1920 × 1080 px (16:9)** 고정.
- 화면에서는 `report.js`가 창 크기에 맞춰 자동 축소(레터박스). **1920×1080 기준으로만 배치**하면 됩니다.
- 콘텐츠 안전 여백: 상하좌우 **112px** (`--pad`).

---

## 2. 컬러 토큰 (`assets/report.css`의 `:root`)

브랜드 톤(딥 퍼플 + 바이올렛) 유지 + 대비·가독성만 다듬은 값.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#23212E` | 본문·제목 기본 글자색 (**소프트 블랙**, 순수 #000 금지) |
| `--ink-2` | `#4B4666` | 보조 설명 글자 |
| `--muted` | `#928DA6` | 캡션·푸터·출처 |
| `--line` | `#E8E5F0` | 얇은 구분선 |
| `--brand` | `#5B3FD4` | 포인트 바이올렛 (라벨·강조 숫자·차트 메인) |
| `--brand-deep` | `#3A2A8F` | 더 진한 강조 (표 헤더 등) |
| `--brand-bg` | `#271C4A` | 표지·간지 다크 배경 |
| `--brand-bg-2` | `#1E1638` | 다크 배경 그라데이션 짝 |
| `--lav` | `#C9BCEC` | 차트 보조(비교값)·연보라 |
| `--lav-soft` | `#EEE9FA` | 옅은 채움·표 줄무늬 |
| `--surface` | `#FFFFFF` | 내용 페이지 배경 |
| `--paper` | `#FCFBFE` | 살짝 톤 다운된 배경 |

**사용 규칙**
- 큰 숫자는 기본 `--ink`, 강조할 때만 `--brand`. 한 화면에서 강조색은 아껴 쓴다.
- 다크 배경 위 글자는 흰색 계열(보조 글자는 흰색 60~70% 투명도).
- 초록/빨강 신호색은 쓰지 않는다. **증감도 브랜드 보라로** 표현.

## 3. 타이포그래피

- **설명/본문(`--font-body`)**: **KoPub돋움(선호)** 또는 Pretendard.
- **제목·큰 숫자(`--font-head`)**: Pretendard(무게 900까지).
- 폰트는 **CSS 변수로만** 지정. 교체는 항상 `:root` 한두 줄.
- 자간은 살짝 좁힘: 기본 `--tracking(-.01em)`, 읽는 텍스트 `--tracking-body(-.02em)`.
- 폰트 종류·특성·파일명 규칙은 **`fonts.md`** 참고.

| 역할 | 클래스 | 크기 | 무게 | 색 |
|---|---|---|---|---|
| 상단 라벨(eyebrow) | `.eyebrow` | 24px / 자간 넓게 / 대문자 | 700 | `--brand` |
| 슬라이드 제목 | `.title` | 52px | 800 | `--ink` |
| 제목 아래 설명 | `.lead` | 28px | 500 | `--ink-2` |
| 본문 | `.body` | 24px / 줄간격 1.65 | 400 | `--ink-2` |
| 큰 스탯 숫자 | `.stat-num` | 108px | 800 | `--ink` 또는 `--brand` |
| 스탯 라벨 | `.stat-label` | 26px | 700 | `--brand` |
| 캡션·출처 | `.caption` | 20px | 400 | `--muted` |
| 푸터 | `.footer` | 20px | 400 | `--muted` |

- 숫자에는 `font-variant-numeric: tabular-nums` (자릿수 정렬).

## 4. 내용 페이지 골격

표지·간지를 제외한 모든 내용 페이지는 이 순서를 지킨다.

```
① eyebrow  (예: 01 DISCOVERY)     ← 보라 작은 라벨
② title    (그 페이지의 핵심 한 문장 = 결론)
③ lead     (제목을 뒷받침하는 회색 설명 한 줄)
④ rule     (가로 실선)
⑤ 본문/차트/표 (자유 배치)
⑥ footer   (좌: 직접 만들고 팔아본 경험으로 마케팅합니다 / 우: PETODAY · 프로젝트명 · N)
```

## 6. 애니메이션 가이드 ⭐

기본 방향: **차분하게, 거들기만.** 내용을 읽는 데 방해가 되면 안 된다. 화려한 효과·튀는 이징은 쓰지 않는다.

### 6.1 원칙
1. **한 슬라이드에 등장 애니메이션은 1~2종류만.** 요소가 순서대로 부드럽게 나타나는 정도.
2. **지속시간 0.4~0.8초, 이징은 `ease-out` 계열.** 튕김(bounce)·회전은 금지.
3. **핵심 숫자에만 강조 모션.** (예: 스탯 숫자 카운트업, 막대·라인 차트 그려지기)
4. **인쇄/PDF에서는 애니메이션을 모두 끈다.** 최종 상태(다 나타난 모습)로 고정.
5. **접근성**: `prefers-reduced-motion: reduce`면 애니메이션을 끄고 최종 상태로 보여준다.

### 6.2 할 수 있는 것 (권장 목록)
- **fade-up 등장**: 요소가 아래에서 살짝 올라오며 나타남(translateY 16px → 0, opacity 0 → 1). 제목→설명→본문 순서로 0.1초씩 지연(stagger).
- **숫자 카운트업**: 큰 스탯 숫자가 0 → 목표값으로 올라감(0.8초). `132.9만`, `+62%` 같은 핵심 지표에만.
- **막대차트 자라기**: 막대가 바닥에서 목표 높이까지 늘어남(scaleY 0 → 1, `transform-origin: bottom`).
- **라인차트 그려지기**: SVG path를 `stroke-dasharray`로 왼쪽부터 그려지게(1.2초).
- **도넛/비율 채우기**: 원호가 0 → 목표 비율까지 채워짐.
- **간지 번호 페이드**: 큰 배경 숫자(01~04)가 은은하게 떠오름.

### 6.3 구현 방식
- 등장 모션은 **CSS 클래스**로 정의한다(예: `.anim-fade-up`). 요소에 클래스를 붙이고, 필요하면 `style="--delay:.2s"`로 순서를 준다.
- 숫자 카운트업·차트 그리기처럼 값이 필요한 모션은 **`report.js`의 작은 헬퍼**로 처리한다(IntersectionObserver로 화면에 보일 때 1회 실행).
- 데이터 속성으로 값을 넘긴다. 예: `<span class="count" data-to="1329000" data-suffix="만"></span>`.
- **모든 애니메이션은 스크린 전용.** `@media print`와 `prefers-reduced-motion`에서 즉시 최종 상태로.

### 6.4 발표용 트랜지션(선택)
- 슬라이드 간 넘김 효과는 각 HTML이 독립 파일이라 기본적으로 없음.
- 필요하면 나중에 전체를 한 파일로 묶는 `deck` 모드에서 좌우 슬라이드 전환(fade/slide 0.4초)만 추가한다. 지금 단계에서는 만들지 않는다.

> 애니메이션은 **기본 OFF에 가깝게** 시작하고, 페이지별로 "여기엔 카운트업" 식으로 하나씩 켠다. 처음부터 전부 넣지 않는다.

## 7. PDF 안전 규칙 ⭐ (내용 누락 방지)

HTML을 PDF로 변환하면 **중간 내용이 사라지거나 빈 페이지가 끼는** 사고가 잦다. 원인은 정해져 있으니, 슬라이드를 디자인할 때 아래를 지킨다. (이 규칙은 실제로 표지에서 빈 페이지가 생겼던 사례에서 나왔다.)

### 7.1 반드시 지킬 것
1. **삐져나가는 장식은 요소가 아니라 `background`로.**
   - ❌ 글로우·워터마크를 `position:absolute` + 음수 위치(`top:-380px`, `bottom:-160px`)로 배치 → `overflow:hidden`이어도 **PDF에서 빈 페이지가 생긴다.**
   - ✅ 슬라이드 배경에 `radial-gradient`(글로우) / `url(...) no-repeat`(워터마크) **레이어**로 넣는다. 배경은 페이지 나눔에 영향을 주지 않는다.
   - 다크 배경용 워터마크는 **흰색으로 미리 만든 SVG**(예: `watermark.svg`, `opacity` 내장)를 쓴다. 배경 이미지는 CSS `filter`로 색을 못 바꾸기 때문.
2. **콘텐츠는 1920×1080 안에 담는다.** 세로로 넘치면 다음 페이지로 밀려 잘린다. 넘칠 것 같으면 요소를 줄이거나 페이지를 나눈다.
3. **배경색·색상 블록에는 색이 그대로 찍히게 한다.** `.slide`에 `print-color-adjust: exact`가 걸려 있다(제거 금지). 없으면 **다크 배경이 흰색으로 인쇄돼 흰 글자가 사라진다.**
4. **화면 맞춤 `transform`은 인쇄에서 해제한다.** `@media print`에서 `.slide{ transform:none; position:static }` 처리됨(이미 적용). 새 레이아웃도 이 전제를 깨지 않는다.
5. **음수 `margin`·거대한 `box-shadow`로 캔버스 밖까지 그리지 않는다.** 인쇄 영역을 넓혀 빈 페이지를 만든다.
6. ⭐ **본문이 `.content-main`을 넘치면 안 된다.** 슬라이드는 `overflow:hidden`이라, 넘친 내용은 **에러 없이 조용히 잘리거나 footer에 가려진다.** (실제로 크리에이터 카드 3장이 footer를 침범한 사고가 있었다.)
   - 특히 **세로 비율 요소(9:16 썸네일)가 카드 높이를 밀어올린다.** 카드를 여러 장 쌓을 땐 썸네일 폭부터 줄인다.
   - 넘치면 요소를 줄이거나(패딩·gap·썸네일), 장수를 나눈다. **footer 위로 올라타게 두지 않는다.**

### 7.2 확인 방법
- ⭐ **넘침 자동 검사**: `report.js`가 `.content-main`의 넘침을 재서 `<html data-overflow="N">`에 기록한다. **N이 0이 아니면 내용이 가려지는 중**이다.
  ```bash
  chrome --headless --dump-dom "file:///.../examples/creator-cards.html" | grep -o 'data-overflow="[0-9]*"'
  ```
  브라우저에서 URL 뒤에 **`?debug`** 를 붙이면 넘친 영역이 빨간 점선으로 표시된다.
- 새 슬라이드를 만들면 **PDF로 한 번 뽑아 페이지 수와 내용**을 확인한다. 파일 1개 = **정확히 1페이지**여야 한다.
- 전체 병합 PDF는 루트의 **`build-report.py`** 로 만든다: 각 HTML을 1페이지 PDF로 인쇄 후 순서대로 병합(`report-output.pdf`). 파일당 1페이지가 보장되므로 내용 누락이 없다.
- 빠른 점검(참고):
  `chrome --headless --print-to-pdf=out.pdf --no-pdf-header-footer "file:///.../cover.html"`
  → 페이지가 2개로 나오면 위 1~5 중 무언가를 어긴 것이다.
